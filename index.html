    2. 

  2. Opłać Tasa 790 código 012 (ok. 12€)
    3. 

  3. Umów Cita Previa w policji lub konsulacie
    4. 

  4. Lub upoważnij prawnika (150-300€)
    5. 


→ sede.policia.gob.es
